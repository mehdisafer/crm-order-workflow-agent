# P06 CRM System API

A tenant-bound Mule system API proxies reviewed requests to the actual Salesforce Apex service. It does not run a second saga. Start the reference runtime with `scripts/launch.sh` to disable the HTTP connector's implicit remotely-closed retries via actual JVM arguments, then inspect the selected process with `scripts/verify_runtime.py`. OAuth refresh on 401 remains an explicit, separately budgeted transport exception. It has an HTTPS listener, an allowlisted path/method surface, explicit OAuth client credentials, bounded concurrency and correlation-only logging.

See [vendor installation and qualification](../../docs/vendor-integration.md). Runtime target: Mule 4.9.24 / Java 17. This source package does not contain a Mule runtime distribution or license. Maven packaging succeeded on 14 November 2026; the [original output and inventory](../../docs/evidence/mule-build-20261114/README.md) retain unresolved external-configuration/TLS warnings and the skipped stream-validation check. XML parsing, RAML review, successful packaging and actual server execution are separate evidence scopes. Deployment and live integration remain unverified.

Maven packaging can be attempted with Java 17, Maven 3.9.0–3.10.0 and the declared public artifact repositories before a Salesforce org or Mule server is available. The plugin explicitly selects the `mule.runtime.version` target.
